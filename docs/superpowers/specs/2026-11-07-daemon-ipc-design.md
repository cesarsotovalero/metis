# M1 O01: local observer daemon

Implement specification sections 6–7 and ticket O01 on the existing four-crate offline foundation. M0's event contract and fixture exit demonstration are complete; its broader identity/release foundations remain partial. This slice supplies the dedicated writer needed for multi-client ingestion without claiming live-agent observation.

The existing contract specifies private length-prefixed JSON IPC, owner authentication, session binding, bounded work and safe errors. Use a new `cs-daemon` crate depending on core/store, with no agent launches, network listeners, models, transformations or paid work. Retain the metadata-only synthetic event contract. The CLI gains foreground `daemon start`, `daemon status` and `daemon stop`; foreground operation avoids installing a service or detaching processes implicitly.

Approaches considered: Tokio-based actor versus standard-library threads with a bounded channel. Choose bounded standard-library connection workers and one SQLite writer thread: there is no async runtime in this codebase, so this meets the current contract without adding one. Implement on Linux first with kernel UID checks through safe nix APIs, a private socket and a 256-bit OS-random owner token. Unsupported platforms return an explicit error while offline import/inspect remain portable.

Protocol: big-endian u32 length, maximum 8 MiB. Requests are `{request_id, operation: {op,...}}`. Hello negotiates protocol version 1, client version, producer/epoch, optional session, requested capabilities and owner token. Grants cover only implemented operations. Append payloads must match the bound session and producer/epoch. Operations: hello, event.append, event.append_batch, session.snapshot, health, shutdown. Unsupported operations never return placeholder success. Responses contain request_id, ok and exactly one typed result or safe structured error.

Defaults: 16 simultaneous connections, writer queue 64, append batch 128 events, 2-second frame/write/dispatch budget. Whole-frame deadlines defend against partial/drip-fed input. All append batches commit atomically and validate the existing schema. Snapshot work is serialized with writes. Queue overflow and failed/expired persistence requests increment observable counters and append bounded metadata-only loss notices to a 64 KiB owner-only spool file; notices contain no events or credentials and are not an event replay buffer. Spool write failures have a separate counter.

Runtime ownership: mode-0700 directories, mode-0600 files/socket, no symlink endpoints, a standard-library exclusive file lock, stale socket/token replacement only under that lock. Startup failures and graceful shutdown clean up owned endpoints. A crash releases the OS lock; a later explicit start may replace stale endpoints. Do not unlink a live server's resources. SQLite and runtime paths are local and owner controlled.

Dispatch timeouts cancel queued work before it begins. A transaction already executing may finish after a timeout, so report an unknown result with no automatic retry; deduplicate explicit reimports by source identities. Shutdown stops accepting clients, bounds idle-client waits, drains accepted writer work and releases endpoints. No arbitrary process kills. External SQLite lock waits must be bounded.

Tests use real sockets, subprocesses and SQLite: authentication/version/session rejection; bounded frames/batches/connections/queues; partial-frame timeout; locked-database timeout; atomic persistence/dedup and restart; runtime permissions/symlinks/singleton; graceful status/stop and unsupported operations. Ordinary CI uses no models or external services.
