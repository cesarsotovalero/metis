# Benchmark evidence

No model calls, paid experiments, token savings, cost savings, or comparative quality measurements have been performed. Fixture totals test accounting correctness only. They are not a benchmark of optimization.

The 100-request synthetic trace exercises reproducible import and report behavior; no latency/RSS targets have been validated. M3 paired task evaluation, isolation, clustered confidence intervals, and missingness analysis remain unimplemented. No experimental features are enabled.

The 35-event contract fixture checks wire coverage, resume reconciliation, task provenance and terminal states. Schema validation overhead, migration throughput and memory/latency budgets have not been benchmarked. Unit/subprocess test pass counts are correctness evidence only.

Daemon tests cover functional admission/deadline bounds using real sockets, held SQLite write reservations and stalled/failing spool sinks. These are regression checks, not the specification's reference-hardware performance measurements. No p95/RSS, 1,000-events/sec, large-ledger query, or multi-user benchmark has been run.
