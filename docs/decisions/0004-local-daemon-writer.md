# ADR 0004: bounded Linux local daemon and dedicated writer

Accepted 2026-11-07. Implement roadmap ticket O01 and its dedicated-writer foundation while preserving the completed offline slice. M0's fixture acceptance demonstration works; broader repository/worktree identity persistence and release validation remain tracked, so neither the whole product nor all foundation requirements are declared done.

Use standard-library threads and bounded channels rather than adding Tokio to a synchronous workspace. Each daemon has one SQLite owner and a bounded number of socket workers. Explicit offline CLI writers remain separate SQLite clients. Reads/updates and old-ledger reconciliation keep existing event semantics. Imports now acquire an immediate write reservation: deferred read-to-write upgrades can bypass SQLite's busy timeout, which made contention fail prematurely and overload tests race.

Linux is the initial daemon target. Safe nix wrappers supply effective UID and kernel peer credentials; a private Unix socket and 256-bit getrandom token provide owner-local authentication. First-party code still forbids unsafe. A standard-library file lock controls singleton/stale cleanup. No global daemon/service configuration is installed; start runs in the foreground, status/stop authenticate as the owner. signal-hook registers graceful SIGINT/SIGTERM handling without unsafe first-party handlers.

Protocol v1 supports authenticated hello, bounded synthetic append/batch, bound snapshot, health and shutdown only. Unsupported artifact/transform/subscription capabilities are not granted. Session/producer/epoch binding is checked for every event before queue admission; database import is atomic. Queued work expires before execution. In-flight work is not advertised as hard-cancellable, and no client request is automatically retried.

The independent review identified synchronous loss-spool I/O on deadline-sensitive paths. Regression tests demonstrated the block. Move notices to a separate bounded background channel; counters/admission remain nonblocking and a stalled sink has a bounded shutdown drain. Its queue/file capacity and I/O errors are observable. The spool holds metadata loss notices, not raw event payloads or replayable telemetry. The producer must retain originals after failure. A second reproducing test caught duplicate expiry counting; only the writer now counts each expired job, including late completion.

Tests use real sockets, SQLite locks, runtime ownership checks and foreground subprocesses. No paid model work, agent permission changes, service installation, publication or remote infrastructure is involved. The Linux socket tests require permission to bind Unix sockets; this sandbox blocks that and the approved tests run outside it. Performance targets, cross-UID negative integration (requires another OS identity), other daemon platforms and live adapters remain unverified.
